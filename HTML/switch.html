Switch Condicional de JavaScript

El switch es una estructura de control que permite evaluar una expresión y ejecutar diferentes bloques de código según el valor de esa expresión.


    let fruta = "manzana";

    switch (fruta) {
        case "naranja":
            console.log("La fruta es una naranja.");
            break;
        case "manzana":
            console.log("La fruta es una manzana.");
            break;
        default:
            console.log("No se reconoció la fruta.");
    }
